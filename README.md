# 篆印工坊

输入汉字，自动生成小篆印章。

**在线使用：https://helioxv022.github.io/zhuanyin/**

<img src="example.png" width="240" alt="朱文方印「許子琦印」">

*朱文方印「許子琦印」。「琦」字《说文》未收，由「玉」「奇」两个部件自动拼合。*

## 功能

- **简体自动转繁**：输入简体，自动对应到《说文》字头，例如「许」变成「許」。
- **缺字自动拼合**：《说文》没收的字，按部件结构自动拼出来，例如「琦」拼成左玉右奇。拼法可以手动调整。
- **印式**：朱文（阳刻）或白文（阴刻）；方印、长方印或圆印。四个字的印还可以选回文排法。
- **刀法**：可以调笔画粗细、边框、字距、字形撑满的程度和残破程度。
- **印泥**：朱磦、朱砂、光明、藏红、墨五种颜色，也可以自选。
- **导出**：2000px 透明底 PNG，或者不带残破效果的 SVG 矢量线稿。

## 使用方法

1. **输入印文**：在「印文」框里输入 1 到 12 个字，简体繁体都可以。
2. **检查每个字**：印面下方每个字有一张卡片，标签的意思是：
   - **说文**：直接用《说文》小篆字形。
   - **拼合**：《说文》未收，按部件拼出来。
   - **缺字**：暂时拼不出来，需要手动填写部件。
3. **调整个别字**：点开「拼合」或「缺字」的卡片，可以：
   - 在「字形」里换成异体字或繁体字的写法；
   - 在「部件拼合」里写结构，例如 `⿰玉奇`（左右结构）、`⿱路鳥`（上下结构）；
   - 用滑块调左边偏旁的宽度，或上半部分的高度。
4. **选择印式和刀法**：残破效果不满意，可以点「换一种残破」重新生成。
5. **导出**：叠到书画上用 PNG；激光雕刻或者再加工用 SVG。

## 排印规则

印面读法是从右到左、从上到下，按字数自动分列：

| 字数 | 排法 |
|---|---|
| 1 | 一个字占满整个印面 |
| 2 | 左右两列 |
| 3 | 右列一个字（通常是姓），左列两个字 |
| 4 | 两列，每列两个字 |
| 5–9 | 三列 |
| 10–12 | 四列 |

**回文排法**（只用于四字印）：姓和「印」字放在右列，名字放在左列。例如「許子琦印」排成右列「許、印」，左列「子、琦」。

## 偏旁写法

部件拼合里，偏旁要写成它在《说文》里对应的本字：

| 偏旁 | 写作 | | 偏旁 | 写作 |
|---|---|---|---|---|
| 氵 | 水 | | 艹 | 艸 |
| 扌 | 手 | | 王（在左边） | 玉 |
| 亻 | 人 | | 阝（在左边） | 阜 |
| 忄 | 心 | | 阝（在右边） | 邑 |
| 讠 | 言 | | 月（肉月旁） | 肉 |

结构符有四种：`⿰` 左右、`⿱` 上下、`⿲` 左中右、`⿳` 上中下。
