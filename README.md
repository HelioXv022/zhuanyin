# 篆印工坊

输入汉字，自动转成小篆并排成印面。纯静态网站，没有后端。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面、界面和印章算法 |
| `g/0.ttf` … `g/119.ttf` | 崇羲篆體按字码分成的 120 块，网页只下载用到的那几块 |
| `chars.txt` | 字库收录的字 |
| `ids.json` | 缺字的部件拼合表（如 琦 = ⿰玉奇） |
| `licenses/` | 字库、数据、代码库的授权文本 |

两个代码库（opentype.js 1.3.4、opencc-js 1.0.5）和界面字体从公共 CDN 加载，需要联网。

## 本地预览

不能直接双击 `index.html` 打开（浏览器会拦住读取字库文件）。在这个文件夹里开一个本地服务器：

```
python3 -m http.server 8000
```

然后浏览器打开 http://localhost:8000

## 上线（任选一种，都免费）

**Netlify Drop（最快，不用写代码）**
打开 https://app.netlify.com/drop ，把整个 `zhuanyin` 文件夹拖进去，几秒后得到一个公开网址。注册后可以改名字、绑自己的域名。

**GitHub Pages**
1. 新建一个仓库（如 `zhuanyin`），把这个文件夹里的所有文件推上去。
2. 仓库 Settings → Pages → Source 选 `main` 分支、根目录。
3. 网址是 `https://<用户名>.github.io/zhuanyin/`。

**挂在自己的网站下**
把整个文件夹放到网站根目录下的一个子目录，比如 `/seal/`，访问 `https://你的域名/seal/` 即可。所有路径都是相对路径，放哪一层都能用。
